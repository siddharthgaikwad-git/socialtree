# 🌱 SocialTree

A simple and modern link-in-bio platform that lets you share all your important links through one personalized page.

## ✨ Features

- 🔗 Create your own SocialTree
- 👤 Add profile/avatar and links
- 👀 Live profile preview
- 🔎 Explore other profiles
- 📱 Fully responsive design
- 🎨 Modern UI with gradients and glassmorphism
- ⚡ Fast and simple to use
- 🔒 Handle is permanent after creation

## 🛠️ Built With

- Next.js
- React
- Tailwind CSS
- MongoDB
- JavaScript

## 🚀 Getting Started

```bash
git clone <your-repository-url>
cd socialtree
npm install
npm run dev
